# Plan 01-01: Lossless context engineering

## Objective

Reduce repeated Luna prompt structure and make context use observable without removing OCR evidence,
page images, grounding, or mandatory dual-engine behavior.

## Tasks

1. Serialize Parse and Markdown grounding evidence as deterministic declared rows.
2. Batch using rendered evidence length and preserve oversized pages without truncation.
3. Keep stable prompt instructions before dynamic configuration and evidence.
4. Export context diagnostics through usage records, Streamlit, and artifact manifests.
5. Add repository-local context guidance, documentation, and focused regression tests.

## Acceptance

- Full pytest suite passes with at least 80% coverage.
- Both modes send every selected image at high detail.
- Compact rows round-trip all evidence fields and are smaller than repeated-key objects.
- No live OpenAI call is required for verification.
